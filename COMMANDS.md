# Dynamic Island - управление и команды

Остров показывает живые активности поверх всего: секундомер, таймер, будильник,
уведомления от других программ и подключение USB/Bluetooth-устройств.

## Как отправить команду

Запустите `DynamicIsland.exe` с аргументами. Если остров уже работает, команда
уйдёт ему и второй экземпляр сразу закроется. Если нет — остров запустится и
сразу применит команду.

```powershell
$DI = "$env:LOCALAPPDATA\DynamicIsland\DynamicIsland.exe"   # или путь к exe в проекте
& $DI stopwatch start
```

### Секундомер

```powershell
& $DI stopwatch start     # запустить
& $DI stopwatch pause     # пауза / продолжить
& $DI stopwatch reset     # сбросить
& $DI stopwatch stop      # убрать с острова
```

Кнопки прямо на острове: **слева** — пауза/продолжить, **справа** — сброс.

### Таймер

```powershell
& $DI timer 10m           # 10 минут
& $DI timer 90s           # 90 секунд
& $DI timer 1h30m         # 1 час 30 минут
& $DI timer 25 "Фокус"    # со своей подписью
& $DI timer pause         # пауза / продолжить
& $DI timer reset         # сброс
& $DI timer +5m           # добавить 5 минут
& $DI timer dismiss       # убрать
```

Кнопки: **слева** — пауза/продолжить, **справа** — сброс. Когда время вышло,
цифры мигают; **слева** — сброс, **справа** — убрать.

### Будильник

```powershell
& $DI alarm 07:30         # сработает в ближайшие 7:30
& $DI alarm snooze        # отложить на 10 минут
& $DI alarm dismiss       # выключить
```

Кнопки: **слева** — «+10» (отложить на 10 минут), **справа** — крестик (выключить).

### Уведомления

```powershell
& $DI notify "Сборка готова" "3 теста упали"
& $DI notify "Просто заголовок"
& $DI clear               # убрать все уведомления
```

Любая программа может показать уведомление таким вызовом — это заменяет
системные всплывающие окна. Кнопка: крестик.

### Приоритет

Если активно несколько вещей, остров показывает по старшинству:

1. будильник
2. таймер
3. секундомер
4. подключённое устройство
5. обычное уведомление

Музыка и микрофон уступают любому из пунктов 1–5.

## USB и Bluetooth

Остров сам сообщает о подключении устройства: показывает иконку (USB-«трезубец»
или значок Bluetooth), имя устройства и **заряд**, если устройство его отдаёт.
Кнопка — крестик.

Заряд показывается не для всех: Bluetooth-наушники обычно сообщают его через
GATT, и Windows не всегда отдаёт это значение системе. Если заряда нет — строка
будет короче, без выдуманных чисел.

## Состояние острова (для отладки)

Рядом с exe пишется файл `island-status.txt` — что остров показывает сейчас.
Удобно, чтобы проверить, дошла ли команда:

```powershell
Get-Content "$env:LOCALAPPDATA\DynamicIsland\island-status.txt"
```

## Размер острова в покое

Правый клик по значку в трее → **Resting width**. От точки (16 px) до 220 px.
Значение хранится в `settings.ini` рядом с exe:

```ini
idlewidth=62
```

Микрофон в работе **не уменьшает** остров — он остаётся выбранной ширины, внутри
появляется оранжевая пиктограмма микрофона и оранжевая окантовка.

## Диагностика

```powershell
& $DI --selftest      # звук, яркость, батарея, DPI, панель задач
& $DI --privacy       # следить за микрофоном в реальном времени
& $DI --probe-media   # проверить доступ к медиа-сессиям (Spotify, VLC, ...)
```

## Языки, радио, загрузки, запуск приложений

### Переключение языка (раскладки)

Показывается автоматически при смене раскладки — просто код: `rus`, `eng`, `ukr`, `deu` и т.д.
Проверить вручную:

```powershell
& $DI lang rus
& $DI lang eng
```

### Bluetooth и Wi-Fi

Показывается автоматически при включении/выключении (3 секунды). Вручную:

```powershell
& $DI radio bluetooth on
& $DI radio wi-fi off
```

### Загрузка файла

Полоска прогресса, проценты и название файла. По завершении остров разворачивается
вниз и показывает зелёную галочку в зелёном круге.

```powershell
& $DI download "setup_installer_x64.exe" 0.42   # 42 %
& $DI download "ubuntu.iso"                     # размер неизвестен - бегущая полоска
& $DI downloaded "setup_installer_x64.exe"      # показать завершение
```

### Открытие приложения

Большая иконка приложения, более ничего. Висит 3 секунды.

```powershell
& $DI app Photoshop
```

Автоматически остров сам замечает новое окно приложения и показывает его иконку.

## Что определяется автоматически

| Событие | Что показывает остров |
|---|---|
| Смена раскладки (Alt+Shift / Win+Space) | код языка: `rus`, `eng`, `ukr` |
| Включение/выключение Bluetooth | значок Bluetooth, 3 секунды |
| Включение/выключение Wi-Fi | значок Wi-Fi, 3 секунды |
| Новое окно приложения | большая иконка приложения, 3 секунды |
| Новый файл в «Загрузках» | зелёная галочка, «Downloaded» |
| Недокачанный файл (.crdownload/.part) в «Загрузках» | полоска с названием |
| Подключение USB/Bluetooth-устройства | карточка с иконкой устройства и зарядом |

Заряд показывается, только если устройство его отдаёт.

## Диагностика датчиков

Показывает, что видят языковой, радио- и оконный датчики, раз в секунду:

```powershell
& $DI --watch
```

Переключите раскладку при работающем `--watch` — должна появиться строка `[LANG] -> eng`.

## Зарядка

Когда ноутбук заряжается, остров показывает проценты и зелёную молнию.
Если в этот момент что-то ещё показывается (музыка, устройство, карточка события),
значок зарядки уезжает **вправо** отдельным островком — как микрофон влево.

Проверка состояния питания:

```powershell
& $DI --charge
```

Проверить вручную:

```powershell
& $DI charging 85      # показать 85%
& $DI charging off     # скрыть
```

Определение автоматическое: `GetSystemPowerStatus`, то есть тот же источник,
что использует сама Windows. На стационарном компьютере без батареи значок
не появляется никогда.

## Иконки приложений

Проверить, что остров видит для открытых окон:

```powershell
& $DI --apps
```

Показывает для каждого окна класс, распознанное имя и найденную иконку
(`32x32` или `NONE (monogram)`). Иконка ищется по четырём источникам:
иконка самого окна, иконка класса окна, иконка exe и иконка файла из оболочки.
Если ничего не найдено, рисуется плитка с **первой буквой названия приложения**.

## Цветные полосы состояния

Остров больше не рисует значки для каждого события — он **подсвечивается цветом**
по верхнему краю. Несколько событий сразу дают несколько секций: часть острова
зелёная, часть оранжевая и так далее.

| Событие | Цвет |
|---|---|
| Зарядка | зелёный |
| Микрофон используется | оранжевый |
| Играет музыка | синий |
| Смена языка | белый |
| Bluetooth / Wi-Fi | красный |
| Загрузка файла | голубой |
| Устройство, уведомление, таймер, будильник, запуск приложения | фиолетовый |

## Полноэкранный режим

Когда любое приложение развёрнуто на весь экран (в том числе Firefox с вкладками),
остров сжимается в **плоскую капсулу 112 x 15** в самом верху экрана, чтобы не
перекрывать вкладки и панели. В этом режиме показываются только цветные полосы —
содержимое и разворачивание отключены.

Выход из полноэкранного режима возвращает обычный вид.
